# Roblox Madden RNG Project

A game combining RNG elements to pull football players and then playing with them in a Madden-styled game.

## The Problem

I like football, but I haven't really gotten into Madden. I've been reluctant to pay for it. I also like Roblox games involving spinning for characters to use within the games. There is nothing that combines both of these in Roblox.

## How It Works

Players pull football players through RNG mechanics (like rolling), with each player having different rarities depending on ratings and positions. Players use their collected football players to build teams and compete against other players in Madden-styled matches. They earn money by playing these matches to pull for more characters.
